# Bitcraft Brand Assets

Static asset repository - no build system.

## Structure

- `logo/` - SVG sources + PNG/favicon exports
- `colors/palette.md` - Color specs with CSS variables
- `typography/fonts.md` - Font specs (Inter, JetBrains Mono)
- `templates/` - HTML templates
- `brandbook/bitcraft-brandbook.html` - Interactive brand guide

## Colors

- Dark Olive: `#556B2F`
- Olive Drab: `#6B8E23`
- Forest Green: `#228B22`

## Writing style

English prose — docs, code comments, commit and PR text, issues, user-visible strings —
follows [Simplified Technical English](https://www.asd-ste100.org/) (ASD-STE100): one
meaning per word, active voice, imperative for instructions, simple tenses, one
instruction per sentence (max 20 words), no jargon or metaphor. Code identifiers are exempt.
